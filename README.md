📊 E-Commerce Sales Analysis Dashboard:


An interactive Power BI dashboard for analysing e-commerce sales performance, profitability, sales targets, customer orders, and regional sales trends using DAX calculations and dynamic visualizations.


📌 Project Overview:


This project presents an interactive Power BI dashboard built to analyze e-commerce sales data. It helps monitor sales performance, compare actual sales against targets, identify profitable product categories, and track order and revenue trends across cities and states — enabling data-driven business decisions.



🧩 Business Problem:


An e-commerce company needs a centralized dashboard to Monitor overall business performance


Compare actual sales against sales targets


Identify the most profitable product categories and sub-categories


Analyze sales distribution across different cities and states


This dashboard was built to address these needs and support better decision-making.


🗂️ Dataset:
The project uses three datasets:


   *List of Orders — customer and order-level details


   *Order Details — product, quantity, sales, and profit data


   *Sales Target — monthly/category-wise target data


🛠️ Tools & Technologies:


   *Microsoft Power BI


   *DAX (Data Analysis Expressions)


   *Power Query


   *Data Modeling


   *Data Visualization


🧮 DAX Calculations:


Calculated Columns


   *Category Type

   
   *Revenue Per Order

   
   *Sales Category

   
Measures


   *Total Sales

   
   *Sales Target

   
   *Order Count

   
   *Average Profit in Delhi

   
   *Year-to-Date (YTD) Sales

   
   *Minimum Target

   
📈 Dashboard Visualizations:

Minimum Target                          (Card)
